# JAI-Tigerfonts Project
Tigerfonts is the be-all end-all solution to everything font-related while customizing your profile in janitor.
This site is intended to assist the process of profile customization by letting you visualize and understand how the different fonts available on the site work, it does not have any additional capabilities nor is it intended to let you import custom fonts of your own.

Created and mantained by tigerdropped (hereby referred to as 'Me', 'Myself', 'I'). 

NOTES:
- This is NOT a tool for bot creation, while custom fonts can work in them, they are tied to miscellaneous classes found on the site.
- Every font listed has been directly extracted from janitorai's source files and personally tested by myself and members of the CSS community. If a font is not listed, that means it only works on your end of the screen.
