# JAI-Tigerfonts Project
Tigerfonts is the be-all end-all solution to your font related issues while customizing your profile.
This site is intended to assist profile customization by letting you visualize and understand how the different fonts available on the site work, it does not have any additional capabilities.

Created and mantained by tigerdropped (hereby referred to as 'Me', 'Myself', 'I'). 

NOTES:
- This is NOT a tool for bot creation.
- Every font listed has been directly extracted from janitorai's source files and personally tested by myself and members of the CSS community. If a font is not listed, that means it only works on your end of the screen.
